Uni-Layer

Understand your layers before you optimize them. Score every layer in your neural network across 13 metrics, then auto-generate pruning, LoRA, and distillation suggestions.

from uni_layer import LayerAnalyzer, LayerProfile

analyzer = LayerAnalyzer(model, task_type='classification')
contributions = analyzer.compute_metrics(data_loader=loader, preset="llm_fast")

profile = LayerProfile(contributions, model_name="bert-base-uncased")
profile.print_report()        # full human-readable report
profile.pruning_suggestion(0.3) # {"safe_to_remove": [...], "estimated_speedup": "25%"}
profile.lora_suggestion(8)      # {"target_layers": [...], "adaptive_ranks": {...}}

Why Uni-Layer?

13 Metrics, One API

Gradient geometry, spectral analysis, information theory, Bayesian uncertainty, robustness, and more — no other tool unifies this many layer importance signals.

LayerProfile Auto-Insights

Redundant layers, bottlenecks, anomalies, depth trends, consensus ranking — all computed on CPU in milliseconds from your metrics output.

Actionable Suggestions

Pruning plans with estimated speedup. LoRA target selection with adaptive rank. Knowledge distillation layer pairing. Ready to use.

Bridge to Your Tools

TorchPruningBridge, HuggingFacePEFTBridge, DistillationBridge — plug Uni-Layer's analysis directly into your optimization pipeline.

HuggingFace Native

Dict outputs, attention_mask, decoder_input_ids — all handled automatically. Verified on 39 models from BERT to LLaMA-3 to CLIP.

Minimal & Fast

Core deps: torch + numpy + tqdm. Works from Python 3.8 to 3.13, PyTorch 2.1 to 2.10. BERT analysis in 0.6s.
