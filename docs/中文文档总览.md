### 2. 核心文档

#### [METRICS_CN.md](METRICS_CN.md)
**指标详解（含数学公式）**

适合：想要深入理解指标原理的用户

这是**最详细**的文档，包含：

**优化几何指标（3种）**

1. **GradientNorm（梯度范数）**
   - 数学公式：$\text{GradNorm} = \|\frac{\partial \mathcal{L}}{\partial \theta}\|_p$
   - 物理意义：测量梯度流强度，反映层的学习活跃度
   - 使用场景：快速筛选重要层、剪枝、蒸馏
   - 计算复杂度：O(BP)，速度1x（最快）

2. **HessianTrace（Hessian迹）**
   - 数学公式：$\text{Tr}(H) \approx \frac{1}{K}\sum_{k=1}^K v_k^T H v_k$
   - 物理意义：测量损失曲面曲率，反映局部最优的锐度
   - 使用场景：评估泛化性能、分析训练稳定性
   - 计算复杂度：O(BKP)，速度6x（最慢）

3. **FisherInformation（Fisher信息）**
   - 数学公式：$F(\theta) = \mathbb{E}[\nabla_\theta \log p(y|x) \nabla_\theta \log p(y|x)^T]$
   - 物理意义：测量参数对输出分布的敏感度
   - 使用场景：持续学习、弹性权重整合、重要性评估
   - 计算复杂度：O(BP)，速度2.5x

**谱与核方法（3种）**

4. **CKA（核对齐）**
   - 数学公式：$\text{CKA}(X,Y) = \frac{\text{HSIC}(K_X, K_Y)}{\sqrt{\text{HSIC}(K_X, K_X) \cdot \text{HSIC}(K_Y, K_Y)}}$
   - 物理意义：测量两层表征的相似性
   - 使用场景：知识蒸馏、模型比较、冗余检测
   - 计算复杂度：O(n²d)，速度2x

5. **EffectiveRank（有效秩）**
   - 数学公式：$\text{EffectiveRank}(X) = \exp(-\sum_i p_i \log p_i)$
   - 物理意义：测量表征的多样性和秩
   - 使用场景：检测特征崩溃、评估容量利用
   - 计算复杂度：O(nd·min(n,d))，速度2x

6. **NTKTrace（神经切线核迹）**
   - 数学公式：$\text{NTKTrace} = \sum_i \|\frac{\partial f(x_i)}{\partial \theta}\|_2^2$
   - 物理意义：测量参数对输出的影响力
   - 使用场景：分析训练动态、特征学习
   - 计算复杂度：O(npc)，速度5x

**信息论指标（2种）**

7. **MutualInformation（互信息）**
   - 数学公式：$I(Z; Y) = H(Y) - H(Y|Z)$
   - 物理意义：测量激活包含的任务相关信息量
   - 使用场景：信息瓶颈分析、层功能理解
   - 计算复杂度：O(ndk log n)，速度2.5x

8. **ActivationEntropy（激活熵）**
   - 数学公式：$H(Z) = -\sum_i p_i \log p_i$
   - 物理意义：测量激活分布的多样性
   - 使用场景：检测死亡神经元、稀疏性分析
   - 计算复杂度：O(nd)，速度1x（最快）

**表征结构（1种）**

9. **JacobianRank（Jacobian秩）**
   - 数学公式：$\text{Rank}(J) = \#\{\sigma_i : \sigma_i > \tau \cdot \sigma_{\max}\}$
   - 物理意义：测量层变换的表达能力
   - 使用场景：评估非线性程度、容量分析
   - 计算复杂度：O(nd_out·d_in²)，速度5x

**鲁棒性指标（1种）**

10. **DropLayerRobustness（DropLayer鲁棒性）**
    - 数学公式：$\Delta\mathcal{L} = \mathcal{L}_{\text{drop}} - \mathcal{L}_{\text{base}}$
    - 物理意义：通过消融直接测量层的必要性
    - 使用场景：验证层重要性、剪枝验证
    - 计算复杂度：O(2BT)，速度3x

**每个指标包含**：
- 数学原理和公式推导
- 物理意义解释
- 计算复杂度分析
- 使用方法和参数说明
- 返回值详解
- 相关研究文献

**阅读时间**：60-90分钟（可按需查阅）

## 💡 使用技巧

### 技巧1：渐进式分析

```python
# 第一步：快速筛选（1分钟）
quick = analyzer.compute_metrics(
    [GradientNorm(num_batches=3)],
    data_loader
)

# 第二步：重点分析（5分钟）
important = analyzer.get_top_k_layers(quick, "gradient_norm", k=10)
detailed = analyzer.compute_metrics(
    [CKA(), EffectiveRank()],
    data_loader,
    layer_names=important
)
```

### 技巧2：多指标融合

```python
# 加权组合多个指标
weights = {
    'gradient_norm': 0.4,
    'cka_score': 0.3,
    'fisher_information': 0.3
}

# 计算综合得分
combined = {
    layer: sum(w * contributions[layer][m] for m, w in weights.items())
    for layer in contributions
}
```

### 技巧3：批量可视化

```python
from uni_layer.visualization import *

# 一次生成所有图表
metrics_to_plot = ["gradient_norm", "cka_score", "effective_rank"]

for metric in metrics_to_plot:
    plot_layer_contributions(
        contributions,
        metric,
        save_path=f"{metric}_analysis.png"
    )
```
